## 📋 Overview

**RespLin App** (Mammography Image Linearizer) is a specialized software tool designed for Medical Physicists and Radiologists. It processes raw mammography data by applying a specific response/conversion function to linearize **DICOM** files, ensuring accurate data analysis and image quality assessment.

## ✨ Key Features

* ☢️ **DICOM Linearization:** Converts raw pixel values using detector response curves.
* 📉 **Accurate Processing:** Implements validated conversion algorithms for mammography.
* 💻 **User-Friendly GUI:** Simple interface for loading, processing, and saving files.
* 🚀 **High Performance:** Optimized for handling large medical image files.
* 💾 **Standard Export:** Saves processed images in compatible DICOM format.
